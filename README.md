# Masal & Zeka Dünyası (GitHub Pages Projesi)

Çocuklar için özel tasarlanmış mobil uyumlu masal okuma, tekerleme ve zeka oyunları web sitesi.

## Dosya Yapısı
- **`index.html`**: Masallar vitrini ve masal okuma alanı.
- **`tekerlemeler.html`**: Hızlı okuma ve diksiyon tekerlemeleri sayfası.
- **`oyunlar.html`**: 4 adet zeka oyunu içeren interaktif oyun salonu.
- **`style.css`**: Tüm sayfaların tasarımını, butonlarını ve renklerini tek yerden yöneten stil dosyası.
